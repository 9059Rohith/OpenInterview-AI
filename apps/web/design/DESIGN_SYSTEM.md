# OpenInterview AI visual specification

Original full dashboard and landing concepts were generated using built-in Image Gen before implementation, alongside a standalone paper staircase illustration. Dashboard composition: fixed 230px navigation rail, hairline top toolbar, open editorial heading, large preparation illustration panel, three action rows, right preparation/focus panel and full-width question prompt. Landing composition: header, split editorial hero with code-native illustrative preview, ownership band, paired modes, capability rows, local-AI band, pricing, FAQ and footer. Public detail pages extend the same component system.

Dark canvas #111315; surfaces #191c1f; text #f6f7f7; secondary #a2a9b0; border #343a3f; chartreuse #d9f279. Light canvas #f5f6f3; surfaces #ffffff; text #182020. UI uses system Inter-compatible sans typography, 15px body, 44px dashboard heading, 62px landing heading, 12–14px labels. Buttons have 9px radius; panels 12px. Icons are Lucide 1.7–2px strokes, typically 16–21px. Grid gutters 20px; panel padding 24px; boundaries are quiet and layout-driven. Motion is short opacity/color changes and respects reduced-motion. Standalone staircase illustration has no overlay, preserves neutral dark background and sits under code-native text.

All metrics come from actual local activity. Preview content is explicitly illustrative. Product mode names are Light Mode and Shadow Mode; appearance is separately called dark/light theme. Secret inputs are never serialized. User content is rendered as text except strict Mermaid SVG output. Deterministic rubric and AI-generated output are visibly distinguished.
