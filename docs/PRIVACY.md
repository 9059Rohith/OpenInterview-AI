# Privacy and data handling

Guest profiles, notes, documents and practice history are stored on the current browser/device. Clearing that storage can erase guest data; export work before switching devices. Local storage is not a cloud backup and is accessible to someone who can use the same OS/browser account.

Browser personal provider keys remain in memory and are sent directly to the selected provider. Closing/reloading the browser clears them. Desktop keys are encrypted using the operating system's protected storage. Deleting a provider key does not delete data already processed by a provider.

Cloud account storage is optional. Upload or sync only after choosing to use the account service. AI generation, transcription and image operations can transmit selected input to the configured provider, whose retention and privacy terms apply. Never include sensitive information unnecessarily. Recording requires a visible user action and appropriate permission from participants.

Operational logs should contain request metadata and sanitized error categories, not raw resumes, keys or transcripts. Operators are responsible for retention, deletion requests, backups and their hosting provider's access logs. Guest data controls and export/delete actions are separate from cloud account deletion.

No private candidate data or personal API key is bundled into the public example dataset. The application is intended for preparation and permitted assistance; it does not implement covert recording or screen-sharing evasion.
